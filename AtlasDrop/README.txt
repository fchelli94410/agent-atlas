ATLAS DROP v1.0.8 — CLASSEMENT AU CLIC MOLETTE

Base cumulative : v1.0.6 validée sous Windows.

Nouveau fonctionnement :
- clic molette directement sur un fichier ou dossier de l'Explorateur ;
- analyse du nom et du contenu utile ;
- proposition prudente d'un dossier OneDrive jusqu'au niveau 5 ;
- boutons OUI, NON, CHOISIR et ANNULER ;
- aucun déplacement sans validation explicite ;
- doublons, gros dossiers, vérification, sons, cache et apprentissage gérés.

Installation : double-cliquer uniquement sur INSTALLER-ET-LANCER-ATLAS-DROP.cmd.
Le programme reste ensuite actif en arrière-plan.

Correction v1.0.8 : reconnaissance renforcée des icônes du Bureau Windows 11,
y compris lorsque le Bureau est redirigé vers OneDrive.
