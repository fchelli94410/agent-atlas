# Sprint 07 — Surveillance robuste des changements

Critères d'acceptation :
1. démarrage/arrêt propre du watcher ;
2. création détectée ;
3. suppression détectée ;
4. renommage détecté avec ancien et nouveau chemin ;
5. changements dans les sous-dossiers détectés ;
6. racine inexistante refusée ;
7. Dispose arrête proprement la surveillance ;
8. erreur interne FileSystemWatcher ne fait pas planter l'application ;
9. aucun fichier OneDrive réel n'est modifié par les tests.
