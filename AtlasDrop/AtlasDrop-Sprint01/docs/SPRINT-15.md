# Sprint 15 — Extraction PDF texte

## Critères d'acceptation automatisables

1. `.pdf` reconnu.
2. Extraction locale du texte natif.
3. Numéro de page conservé dans le résultat.
4. Limite de caractères configurable.
5. Limite de pages configurable.
6. Fichier absent refusé clairement.
7. Mauvaise extension refusée.
8. Annulation respectée.
9. PDF source jamais modifié.
10. Aucun OCR déclenché dans ce sprint.
11. Tests uniquement sous `%TEMP%`.

## Preuve attendue

Compilation Release sans erreur + tous les tests Sprint 1 à 15 réussis.
