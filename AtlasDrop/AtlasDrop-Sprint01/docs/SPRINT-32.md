# Sprint 32 — Signaux de similarité fichiers

## Critères d'acceptation automatisables

1. Similarité basée sur type documentaire.
2. Similarité basée sur mots-clés.
3. Similarité basée sur lieux.
4. Similarité basée sur entreprises.
5. Similarité basée sur années.
6. Similarité possible via nom de fichier proche.
7. Accents/casse normalisés.
8. Fichiers sans rapport : score 0.
9. Dossier contenant des fichiers similaires reçoit un bonus limité.
10. Le bonus de similarité ne peut jamais contourner les exclusions.
11. Le bonus ne peut jamais contourner la limite de profondeur automatique > 4.
12. Aucun fichier utilisateur modifié.

## Preuve attendue

Compilation Release sans erreur, 0 avertissement, puis tous les tests Sprint 1 à 32 réussis.
