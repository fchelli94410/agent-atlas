# Sprint 26 — Classification du type documentaire

## Critères d'acceptation automatisables

1. Facture détectée via signaux métier.
2. Devis détecté.
3. Contrat/convention détecté.
4. Bon de commande détecté.
5. Rapport/compte rendu détecté.
6. Relevé détecté.
7. Reçu/ticket détecté.
8. Extensions XLSX/CSV/PPTX/MSG/ZIP/images utilisées comme signaux forts.
9. PDF générique ne force aucun type.
10. Résultat inconnu conservé si aucun signal fiable.
11. Confiance bornée entre 0 et 1.
12. Raisons explicables pour le type retenu.
13. Aucun fichier utilisateur modifié.

## Preuve attendue

Compilation Release sans erreur, 0 avertissement, puis tous les tests Sprint 1 à 26 réussis.
