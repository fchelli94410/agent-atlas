# Sprint 08 — Identité stable après renommage/déplacement

Critères d'acceptation :
1. un renommage peut conserver le StableId ;
2. un déplacement peut conserver le StableId ;
3. un dossier sans rapport n'est jamais fusionné ;
4. un chemin identique est reconnu avec confiance maximale ;
5. une situation ambiguë n'est pas associée automatiquement ;
6. un candidat unique et cohérent est réconcilié ;
7. aucune donnée d'historique n'est supprimée ;
8. aucun fichier OneDrive réel n'est modifié dans les tests.
