# Sprint 04 — Scan initial complet

## Critères d'acceptation automatisables

1. Scan récursif d'une racine existante.
2. La racine et tous ses sous-dossiers accessibles sont retournés.
3. La profondeur de chaque dossier est calculée.
4. Le dossier parent est connu.
5. Le nombre de fichiers est compté.
6. Les extensions présentes sont recensées.
7. Une progression est remontée.
8. L'annulation est supportée.
9. Les reparse points et dossiers système sont ignorés.
10. Le scan ne modifie aucun fichier.

## Preuve attendue

Compilation Release sans erreur + tous les tests Sprint 1 à 4 réussis.
