# Sprint 14 — Extraction PPTX

## Critères d'acceptation automatisables

1. `.pptx` reconnu.
2. Lecture sans Microsoft PowerPoint installé.
3. Texte d'une diapositive extrait.
4. Plusieurs diapositives supportées.
5. Numéro de diapositive présent dans le texte extrait.
6. Limite de caractères configurable.
7. Limite de diapositives configurable.
8. Fichier absent refusé clairement.
9. Mauvaise extension refusée.
10. Annulation respectée.
11. Le PPTX source n'est jamais modifié.
12. Tests uniquement sous `%TEMP%`.

## Preuve attendue

Compilation Release sans erreur + tous les tests Sprint 1 à 14 réussis.
