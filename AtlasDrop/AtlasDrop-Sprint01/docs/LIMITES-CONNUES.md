# Limites connues — V1

- Windows 11 / x64.
- Un utilisateur Windows à la fois.
- OneDrive local configuré sur la machine.
- Certaines fonctions OCR peuvent être plus lentes sur de gros documents.
- La profondeur automatique de suggestion est limitée à 4 niveaux.
- Les dossiers plus profonds peuvent rester indexés mais ne sont pas proposés automatiquement.
- Aucun traitement cloud externe.
- Aucun classement automatique à faible confiance.
- Les contrôles visuels finaux de l’interface doivent être effectués sur la machine Windows cible.
