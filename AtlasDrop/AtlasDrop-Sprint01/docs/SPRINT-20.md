# Sprint 20 — Normalisation texte et variantes

1. Casse ignorée.
2. Accents supprimés.
3. Tirets/slash/underscore/ponctuation normalisés.
4. Espaces multiples normalisés.
5. Variantes Saint Maurice / Saint-Maurice / stmaurice reconnues.
6. Montévrain / Montevrain équivalents.
7. Aliases personnalisables.
8. Normalisation idempotente.
9. Chaînes vides/null gérées.
10. Aucun fichier utilisateur modifié.
