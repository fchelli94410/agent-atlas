# Sauvegarde / restauration

## Éléments à sauvegarder

Le dossier :

`%LOCALAPPDATA%\AtlasDrop`

peut contenir :
- base locale ;
- configuration ;
- apprentissage ;
- journaux.

## Sauvegarde

Fermer Atlas Drop puis lancer `SAUVEGARDER-ATLAS-DROP.cmd`.

## Restauration

Fermer Atlas Drop puis lancer `RESTAURER-ATLAS-DROP.cmd` avec le dossier de sauvegarde souhaité.

La restauration n’écrase pas silencieusement une installation en cours : une copie de sécurité préalable est créée.
