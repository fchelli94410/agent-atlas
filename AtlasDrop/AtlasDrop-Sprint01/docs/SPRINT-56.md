# Sprint 56 — Notifications, sons et inactivité

## Critères d'acceptation automatisables

1. Son Windows au lancement.
2. Son Windows de succès.
3. Son Windows de rappel.
4. Aucun fichier audio externe requis.
5. Rappel après 45 secondes d'inactivité par défaut.
6. Aucun rappel pendant la saisie.
7. Une activité utilisateur réarme le délai.
8. Un rappel n'est pas répété tant qu'aucune nouvelle activité n'a eu lieu.
9. Message visuel discret d'attente.
10. Timer WPF arrêté avec la fenêtre via cycle de vie normal.
11. Aucun réseau ni service externe.
12. Les sons restent non bloquants pour le fonctionnement principal.

## Preuve attendue

Compilation Release sans erreur, 0 avertissement, puis tous les tests Sprint 1 à 56 réussis.
