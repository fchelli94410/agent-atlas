# Sprint 53 — Désactivation / réinitialisation apprentissage

## Critères d'acceptation automatisables

1. Apprentissage activé par défaut.
2. Désactivation empêche l'enregistrement de nouveaux événements.
3. Désactivation ne supprime pas automatiquement l'historique existant.
4. Réactivation possible.
5. Réinitialisation supprime les événements existants.
6. Réinitialisation reste disponible même si apprentissage désactivé.
7. Interface expose activation/désactivation.
8. Interface expose réinitialisation.
9. Le scoring continue de fonctionner sans apprentissage.
10. Aucune règle de sécurité/exclusion n'est modifiée.

## Preuve attendue

Compilation Release sans erreur, 0 avertissement, puis tous les tests Sprint 1 à 53 réussis.
