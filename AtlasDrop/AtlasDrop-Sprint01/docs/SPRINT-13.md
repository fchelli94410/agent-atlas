# Sprint 13 — Extraction XLSX

## Critères d'acceptation automatisables

1. `.xlsx` reconnu.
2. Lecture sans Microsoft Excel installé.
3. Noms de feuilles extraits.
4. Valeurs de cellules extraites.
5. Plusieurs feuilles supportées.
6. Limite de caractères configurable.
7. Limite de cellules configurable.
8. Fichier absent refusé clairement.
9. Mauvaise extension refusée.
10. Annulation respectée.
11. Le XLSX source n'est jamais modifié.
12. Tests uniquement sous `%TEMP%`.
