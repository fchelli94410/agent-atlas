# Atlas Drop — Guide utilisateur

## Utilisation normale

1. Dans l’Explorateur Windows, clic droit sur un fichier.
2. Choisir **Ranger avec Atlas Drop**.
3. Vérifier les informations détectées.
4. Choisir une des trois suggestions ou rechercher un dossier.
5. Ajuster le nom proposé si nécessaire.
6. Cliquer sur **Classer**.
7. Atlas Drop vérifie la destination, les conflits et l’intégrité du déplacement.

## Raccourcis

- Entrée : classer.
- Échap : annuler.
- Flèches : changer de suggestion.
- 1 / 2 / 3 : sélectionner directement une suggestion.
- F : aller à la recherche.

## Sécurité

- Aucun écrasement automatique.
- En cas de conflit : `(2)`, `(3)`, etc.
- Doublon exact SHA-256 : signalé, jamais supprimé automatiquement.
- Destination automatique limitée aux niveaux 1 à 4 sous OneDrive.
- Dossiers exclus jamais proposés automatiquement.
- Aucun fichier n’est envoyé vers un service externe.
