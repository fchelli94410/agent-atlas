# Installation

## Installation finale

1. Lancer `AtlasDrop.Installer.exe`.
2. L’application est installée dans `%LOCALAPPDATA%\AtlasDrop\App`.
3. Le menu **Ranger avec Atlas Drop** est ajouté au clic droit des fichiers.
4. Aucun droit administrateur n’est requis.

## Désinstallation

Lancer :

`AtlasDrop.Installer.exe --uninstall`

Le menu contextuel et l’application sont supprimés.

Les données utilisateur et journaux ne sont pas supprimés implicitement.
